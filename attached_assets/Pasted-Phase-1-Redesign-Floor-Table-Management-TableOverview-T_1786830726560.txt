Phase 1: Redesign Floor & Table Management (TableOverview & TableCard)

Refactor `src/screens/TableOverview.tsx` and `src/components/tables/TableCard.tsx` to match the new high-contrast, adaptive theme design:

1. Adaptive Theme Tokens & Card Surfaces:
   - Remove all hardcoded dark classes (e.g. `bg-[#0b...], bg-slate-900`).
   - Use dynamic semantic Tailwind tokens (`bg-card`, `text-card-foreground`, `border-border`, `bg-background`).
   - In Dark Mode: Elevated matte slate-charcoal cards with crisp borders.
   - In Light Mode: Crisp pure white cards with soft ambient shadow and defined borders.

2. Table Card Content & Layout (`TableCard.tsx`):

     * Occupied: High-visibility warm amber badge with a subtle glowing border/ring.

     * Pax Count (e.g., "👥 2 Pax") in high-contrast text.
     * Live Timer (e.g., "⏱ 49m") in high-contrast ice-silver (dark) / dark charcoal (light).
     * Customer Name (e.g., "👤 Amit Dai") displayed only if a customer is attached.

3. Floor Headers & Filter Bar (`TableOverview.tsx`):

4. Tactile Interactions:
   - Add smooth hover lift (`hover:-translate-y-0.5 hover:border-primary/50 transition-all duration-150`).
