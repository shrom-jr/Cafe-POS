PHASE 6: DYNAMIC OS PRINTER DISCOVERY & SILENT PRINT ROUTING VIA ELECTRON

Upgrade the Electron print architecture so printer names are never hardcoded. Allow admins to dynamically discover all installed Windows printers and assign them to Kitchen and Reception stations via dropdowns in Settings.

1. ELECTRON MAIN PROCESS PRINTER DISCOVERY & SILENT IPC (`electron/main.js`):
   - Expose an IPC handler to fetch installed OS printers:
     `ipcMain.handle('get-printers', async (event) => {`
     `  const win = BrowserWindow.fromWebContents(event.sender);`
     `  return await win.webContents.getPrintersAsync();`
     `});`
   - Expose an async silent print handler that accepts an explicit `deviceName`:
     `ipcMain.handle('silent-print', async (event, { html, deviceName }) => {`
     `  const printWin = new BrowserWindow({ show: false, width: 302, height: 600, webPreferences: { nodeIntegration: false, contextIsolation: true } });`
     `  await printWin.loadURL(`data:text/html;charset=utf-8,${encodeURIComponent(html)}`);`
     `  return new Promise((resolve) => {`
     `    printWin.webContents.print({`
     `      silent: true,`
     `      printBackground: true,`
     `      margins: { marginType: 'none' },`
     `      deviceName: deviceName || undefined`
     `    }, (success, failureReason) => {`
     `      printWin.destroy();`
     `      if (!success) resolve({ success: false, error: failureReason });`
     `      else resolve({ success: true });`
     `    });`
     `  });`
     `});`

2. EXPOSE APIS IN PRELOAD & TYPES (`electron/preload.js` & `src/types/electron.d.ts`):
   - In `electron/preload.js`:
     `getPrinters: () => ipcRenderer.invoke('get-printers'),`
     `printSilent: (html, deviceName) => ipcRenderer.invoke('silent-print', { html, deviceName }),`
     `isElectron: true`
   - Update `src/types/electron.d.ts` with typed definitions for `getPrinters()` and `printSilent()`.
